# Future goals

## Broaden benchmark and grader coverage

Import more redistributable benchmark tasks. Add graders and environments that
follow the original scoring rules, including benchmarks that need executable
tests, simulated tools, or a judge. [Adding a benchmark](adding-a-benchmark.md)

## Configure model ladders

Define stronger model and profile sequences for benchmark families. Measure
which stages solve earlier failures, set request and cost bounds, and show
each open task's progress through the configured sequence.

## Scale trajectory storage

Keep complete trajectories and first-solve attribution as evaluation volume
grows. Use a lightweight index for browsing and selecting work, with links to
the durable history.
