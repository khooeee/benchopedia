# NarrativeQA redistribution review

## Scope

The snapshot contains the complete official test split of NarrativeQA at commit `904246f6d1fe99a99a08a03501fe3e619af2cee5` of google-deepmind/narrativeqa: all 10,557 questions of that split, both reference answers recorded for each, and the Wikipedia plot summary of each of the 355 books and film scripts they ask about, together with the title and kind of each story. The training and validation splits, the tokenised copies of the questions, answers, and summaries, and the full texts of the stories are not imported. The full texts are not in the upstream repository at all: it ships a script that downloads them from Project Gutenberg and from film-script websites, and this snapshot neither downloads nor reproduces them. Both the public repository and the website publish this content. No code or images are copied. [Repository at the pinned commit](https://github.com/google-deepmind/narrativeqa/tree/904246f6d1fe99a99a08a03501fe3e619af2cee5)

## Terms

The repository carries the Apache License 2.0 as its `LICENSE` file, which is kept beside this review as `LICENSE`, and its metadata block names that license for the dataset. Apache 2.0 permits reproduction and distribution of the work and of derivative works, in source or other form, when the license is included, the notices are kept, and changed files are marked. The repository has no access gate, no registration, and no separate terms page. The questions and answers were written by Amazon Mechanical Turk workers hired by the authors and are covered by that grant. [License at the pinned commit](https://github.com/google-deepmind/narrativeqa/blob/904246f6d1fe99a99a08a03501fe3e619af2cee5/LICENSE)

The plot summaries are held separately and under separate terms. They sit in `third_party/wikipedia/`, beside a copy of the Creative Commons Attribution-ShareAlike 3.0 Unported legal code and a one-line `ATTRIBUTION` file reading: "Wikipedia summaries were produced by authors of their respective pages. Links are available in documents.csv in the column wiki_url." That legal code is kept beside this review as `LICENSE-wikipedia-summaries`. It permits copying, distribution, public display, and adaptation when the work is credited, the license is named, notices are kept, and adaptations are shared under the same or a compatible later version of the terms, so this snapshot carries a share-alike notice for the summaries and uses the links upstream provides: the generated `ATTRIBUTION.md` lists all 355 stories with the Wikipedia address recorded for each, and each task prompt names the story its summary describes. The summaries are Wikipedia prose as of 2017; the dataset does not record which revision each came from. [Third-party directory at the pinned commit](https://github.com/google-deepmind/narrativeqa/tree/904246f6d1fe99a99a08a03501fe3e619af2cee5/third_party/wikipedia) and [legal code](https://creativecommons.org/licenses/by-sa/3.0/legalcode)

The stories themselves are the part of this dataset that cannot be republished, and they are the part upstream does not ship. Project Gutenberg texts are public domain in the United States but carry the Project Gutenberg trademark terms when redistributed with their headers, and the film scripts are hosted on third-party sites with no license grant at all. Nothing in this snapshot copies them, and no task depends on them: every question was written from the plot summary, which is what the prompt gives. The upstream `documents.csv` records a story address for each document for researchers who want the full-story setting; those addresses are not reproduced here. [Repository README at the pinned commit](https://github.com/google-deepmind/narrativeqa/blob/904246f6d1fe99a99a08a03501fe3e619af2cee5/README.md)

A scan of the imported text found no contact details, identifiers, or other personal data. The summaries describe fictional plots, and the questions and answers concern those plots; the crowdworkers who wrote them are not identified anywhere in the data.

## Changes

Benchopedia assembles each task prompt from the question, two lines naming the story and its kind as upstream records them, and the plot summary. Questions, answers, titles, and summary text are unchanged, except that the surrounding whitespace of each summary is removed, which every summary has; the line breaks inside a summary are kept. The upstream kinds are written as recorded, `movie` for a film script and `gutenberg` for a book.

The reference solution is the two answers the annotators gave, one per line, in the upstream order. Upstream records no identifier for a question, so keys are built from the story's document identifier and the question's position among that story's questions in the pinned question file. Prompt and solution links point at that question's line in the question file at the pinned commit; the environment link is omitted, since the full story this snapshot does not reproduce would be the only candidate.
