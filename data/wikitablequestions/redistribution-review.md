# WikiTableQuestions redistribution review

## Scope

The snapshot contains the complete official test split of WikiTableQuestions, `data/pristine-unseen-tables.tsv` at commit `7d455a5a707b96341ef72aff9428749d443d8aa9` of ppasupat/WikiTableQuestions: 4,344 questions, their reference answers, and the 421 tables they ask about, each reproduced from the upstream comma-separated table file. The page title recorded beside each table is included, and the exact page revision is recorded in the accompanying `ATTRIBUTION.md`. The training split, the seen-tables portion, the development splits, the annotated logical forms, the CoreNLP-tagged copies, the tab-separated and column-aligned renderings of the tables, the extracted HTML tables, and the raw HTML of the source pages are not imported. Both the public repository and the website publish this content. No code or images are copied. [Test split at the pinned commit](https://github.com/ppasupat/WikiTableQuestions/blob/7d455a5a707b96341ef72aff9428749d443d8aa9/data/pristine-unseen-tables.tsv) and [table files](https://github.com/ppasupat/WikiTableQuestions/tree/7d455a5a707b96341ef72aff9428749d443d8aa9/csv)

## Terms

The repository carries the full Creative Commons Attribution-ShareAlike 4.0 International license text as its `LICENSE` file, which is kept beside this review as `LICENSE`. That license permits copying, redistribution, public display, and adaptation when the work is credited, a link to the license is given, notices are kept, changes are indicated, and adaptations are shared under the same terms. The repository has no access gate and no separate terms page, and the project page states no other terms. The license applies to the dataset as published, which includes the questions, the answers, and the extracted tables. [License at the pinned commit](https://github.com/ppasupat/WikiTableQuestions/blob/7d455a5a707b96341ef72aff9428749d443d8aa9/LICENSE) and [project page](https://ppasupat.github.io/WikiTableQuestions/)

The tables are converted from English Wikipedia pages, so they carry Wikipedia's own terms as well. Wikipedia text is shared under CC BY-SA, and Wikipedia's reuse guidance accepts a link to the article as credit to its contributors; earlier CC BY-SA versions allow adaptations under version 4.0, so publishing these tables under CC BY-SA 4.0 is consistent with Wikipedia's terms. Unlike most datasets built from Wikipedia, this one records the exact revision each table came from, so attribution can point at the page as it stood: the generated `ATTRIBUTION.md` lists all 421 pages with permalinks to those revisions, and each task prompt names its page. Five of the 421 pages have since been deleted from Wikipedia, so their revisions are gone and their permalinks no longer resolve: "Opinion polling by state for the United States presidential election, 2008 (Iowa)", "List of international cricket centuries at Eden Gardens", "Comparison of educational websites for children", "List of experiments from Lilo & Stitch", and "List of 2008 New Zealand fuel economy ratings". Another 82 pages have been renamed since the tables were extracted. The questions and answers were written by Amazon Mechanical Turk workers hired by the authors. [Wikipedia's reuse terms](https://en.wikipedia.org/wiki/Wikipedia:Reusing_Wikipedia_content) and [paper](https://arxiv.org/abs/1508.00305)

A scan of the imported text found no contact details, identifiers, or other personal data beyond what Wikipedia tables record about public figures, such as the names, nationalities, and results of athletes, politicians, and performers. The upstream README gives the maintainer's email address; it is not reproduced here.

## Changes

Benchopedia assembles each task prompt from the question, a line naming the source Wikipedia page, and the table's comma-separated file inside a fenced block. The reference solution is the answer, with the items of a list answer written one per line instead of pipe-separated. Keys are the upstream example IDs, prompt and solution links point at the question's line in the split file at the pinned commit, and the environment link points at the table file. Question, table, and answer text is unchanged, including one page title that upstream records with an HTML entity, and the escapes the upstream tab-separated files define are undone as the official evaluator undoes them.

## Notices
