# Moral Stories Consequence Plausibility redistribution review

## Scope

Benchopedia publishes the crowd-authored action and consequence, original row ID, and binary label for all 4,000 records in the original `consequence+action/minimal_pairs` test file. The pinned Hugging Face revision is `b830cf56eb00bc4edd1860dd544a192216eb3587`. The file SHA-256 is `d9f5bf6811442bebb52ced6e46798ca9e2b1996d65c83a5e06972f066d4c183f`. The separate story norm, situation and intention fields are outside this task setting. [Pinned test file](https://huggingface.co/datasets/demelin/moral_stories/blob/b830cf56eb00bc4edd1860dd544a192216eb3587/data/classification/consequence%2Baction/minimal_pairs/test.jsonl) [Dataset collection and task settings](https://arxiv.org/html/2012.15738)

## Changes

Benchopedia presents the published action and consequence under text labels and gives each record its original row ID. It displays released labels 1 and 0 as plausible and implausible. Each story's two original pairs and two exchanges are included.
