# BBQ redistribution review

## Scope

The snapshot contains all 58,492 examples in the 11 category files of the data folder at commit `bea11bd97d79217245b5871acd247b9d6eb24598` of nyu-mll/BBQ: each example's context, question, three answer options, and correct answer. The answer metadata, stereotyped-group annotations, source links, templates, vocabulary, validation data, and model results in the repository are not included. Both the public repository and the website publish this content. No code or images are copied. [Data folder](https://github.com/nyu-mll/BBQ/tree/bea11bd97d79217245b5871acd247b9d6eb24598/data)

## Terms

The repository contains the full legal text of the Creative Commons Attribution 4.0 International license, and the paper states that the full dataset is released under CC BY 4.0. The license permits copying, redistribution, public display, and adaptation when the work is credited, a link to the license is given, and changes are stated. It adds no non-commercial or share-alike condition. [License text](https://github.com/nyu-mll/BBQ/blob/bea11bd97d79217245b5871acd247b9d6eb24598/LICENSE) and [paper](https://aclanthology.org/2022.findings-acl.165/)

The paper states that each template was written from scratch by the authors, and the examples are generated by filling those templates from the authors' vocabulary. The repository has no access gate or separate restriction on publishing the examples. [README](https://github.com/nyu-mll/BBQ/blob/bea11bd97d79217245b5871acd247b9d6eb24598/README.md)

## Changes

Benchopedia joins each context, question, and lettered answer options into one prompt, stores the correct option's letter and text as the reference answer, builds IDs from the category and upstream example ID, and adds source links. Context, question, and answer text is unchanged.
