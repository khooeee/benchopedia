# HotpotQA redistribution review

## Scope

The snapshot contains the complete official development split of HotpotQA in the distractor setting, the published file `hotpot_dev_distractor_v1.json` whose SHA-256 digest is `4e9ecb5c8d3b719f624d66b60f8d56bf227f03914f5f0753d6fa1b359d7104ea`: 7,405 multi-hop questions, their answers, the sentences a crowdworker marked as the supporting facts, and the ten Wikipedia paragraphs given with each question, each reproduced with the article title it came from. The training split, the development split in the fullwiki setting, the unlabelled fullwiki test split, the authors' processed Wikipedia corpus, and the evaluation script are not imported. Both the public repository and the website publish this content. No code or images are copied. [Project page](https://hotpotqa.github.io/) and [snapshot of the official download link](https://web.archive.org/web/20260310132809id_/http://curtis.ml.cmu.edu/datasets/hotpot/hotpot_dev_distractor_v1.json)

The authors' own download host, `curtis.ml.cmu.edu`, no longer resolves, so the file cannot be fetched from the link the project page gives. This snapshot takes it from the Internet Archive's copy of that exact link and pins it by digest, so the bytes imported are verifiably the authors' file rather than whatever a mirror has made of it. A second, independent copy is published on Hugging Face by the authors' organisation under the same terms; its distractor validation split has the same 7,405 rows, and its first row carries the same question identifier, question, answer, supporting facts, and ten paragraph titles in the same order as the archived file. [Hugging Face copy](https://huggingface.co/datasets/hotpotqa/hotpot_qa)

## Terms

The project page states, in the sentence that introduces the download links, "HotpotQA is distributed under a CC BY-SA 4.0 License", with the words linking the Creative Commons Attribution-ShareAlike 4.0 International deed. The same page states the same terms again for the processed Wikipedia corpus the paragraphs were drawn from. That grant permits copying, redistribution, public display, and adaptation when the work is credited, a link to the terms is given, notices are kept, changes are indicated, and adaptations are shared under the same terms. The files were served without an access gate, registration, or click-through agreement, and the Hugging Face copy declares the same terms in its dataset card. Submitting a model for a test-set score needs a CodaLab account, but nothing about the published development split does. [Project page](https://hotpotqa.github.io/) and [legal code](https://creativecommons.org/licenses/by-sa/4.0/legalcode)

The paragraphs are English Wikipedia prose, so they carry Wikipedia's own terms as well. Wikipedia text is shared under CC BY-SA, and Wikipedia's reuse guidance accepts a link to the article as credit to its contributors; adaptations of earlier CC BY-SA versions may be published under version 4.0, so sharing this text under CC BY-SA 4.0 is consistent with those terms. The authors built the paragraphs from the English Wikipedia dump of 1 October 2017, extracting the first paragraph of each article and segmenting it into sentences with Stanford CoreNLP 3.8.0; the dataset records each paragraph's article title but not the revision it came from, so attribution can only point at the article. The generated `ATTRIBUTION.md` lists all 66,581 articles that appear in this split with links to them, and every task prompt names the article each paragraph belongs to. The questions, answers, and supporting-fact annotations were written by Amazon Mechanical Turk workers hired by the authors. [Processed Wikipedia README](https://hotpotqa.github.io/wiki-readme.html) and [Wikipedia's reuse terms](https://en.wikipedia.org/wiki/Wikipedia:Reusing_Wikipedia_content)

A scan of the imported text found no contact details, identifiers, or other personal data beyond what Wikipedia records about notable people, organisations, and places: the paragraphs are article openings, so dates of birth, family relationships, and deaths appear throughout, as they do in the encyclopedia. The crowdworkers who wrote the questions are not identified anywhere in the data.

## Changes

Benchopedia assembles each task prompt from the question followed by the ten paragraphs, each introduced by a heading holding its article title. A paragraph is written as its sentences joined back together, which restores the paragraph as the authors extracted it; the upstream sentence list is the segmentation the supporting-fact annotation refers to, not a change to the text. Questions, answers, titles, paragraph text, and the order of the paragraphs are unchanged, so a task shows the shuffled ten paragraphs exactly as upstream records them.

The reference solution is the answer, then the supporting facts in the order upstream lists them, one per line as the article title, the sentence number, and that sentence. Sentence numbers are the upstream indices, which count from zero. One supporting fact in this split names a sentence number that does not exist in its paragraph, so its line gives the recorded title and number with no sentence text. The `yes` and `no` answers are written as upstream stores them. Keys are the upstream question identifiers. Prompt and solution links point at the pinned split file, which has no per-question addresses, and the environment link is omitted.

The grader adds a generated table of sentence end offsets for the same pinned split. It contains task IDs and integer positions only, is covered by the same attribution and share-alike terms, and preserves the source sentence numbering without adding article text to the catalog.

## Notices

HotpotQA is from "HotpotQA: A Dataset for Diverse, Explainable Multi-hop Question Answering" by Zhilin Yang, Peng Qi, Saizheng Zhang, Yoshua Bengio, William W. Cohen, Ruslan Salakhutdinov, and Christopher D. Manning, EMNLP 2018, a collaboration of Carnegie Mellon University, Stanford University, and Université de Montréal. The questions, answers, and supporting-fact annotations were written by crowdworkers.

The paragraphs are English Wikipedia prose written by Wikipedia contributors, taken from the dump of 1 October 2017. All 66,581 articles that appear in this split are credited by title and linked in the `ATTRIBUTION.md` that accompanies this snapshot, and each task prompt names the article every paragraph belongs to. HotpotQA does not record which revision of each article its paragraph came from.

The authors publish no license file beside the data, so no upstream file accompanies this snapshot. Adaptations of these questions, answers, supporting facts, and paragraphs must remain under those terms. Benchopedia's MIT license does not replace them.
