# MuSR redistribution review

## Scope

The snapshot contains all 756 questions, their narratives, choices, and reference answers from the three dataset files at commit `b1f4d4168a9cfc6760e8b74d728e4516023dfaa5` of Zayne-sprague/MuSR: murder_mystery.json, object_placements.json, and team_allocation.json. The reasoning trees and intermediate data stored with each question are not included. Both the public repository and the website publish this content. No code or images are copied. [Dataset files](https://github.com/Zayne-sprague/MuSR/tree/b1f4d4168a9cfc6760e8b74d728e4516023dfaa5/datasets)

## Terms

The repository, which the paper links as the project's home, carries the MIT license with a 2024 copyright notice for Zayne Sprague. MIT permits copying, redistribution, and public display when the copyright and permission notice is retained. The authors' Hugging Face copy of the same questions declares CC BY 4.0, which also permits redistribution with attribution; this snapshot credits the authors and links that license as well. The paper describes the narratives as written by GPT-4 from reasoning trees generated by the authors' pipeline, rather than drawn from other published text. Neither source has an access gate or a separate restriction on publishing the questions. [License](https://github.com/Zayne-sprague/MuSR/blob/b1f4d4168a9cfc6760e8b74d728e4516023dfaa5/LICENSE), [Hugging Face card](https://huggingface.co/datasets/TAUR-Lab/MuSR/blob/7c365b439a222150f317764d4f16ae6c96d7d94a/README.md), and [original paper](https://arxiv.org/abs/2310.16049)

## Changes

Benchopedia joins each narrative, question, and numbered choices into one prompt, stores the correct choice number and text as the answer, assigns IDs from the domain and question order, and adds source links. Narrative, question, and choice text is unchanged.
