# CLadder redistribution review

## Scope

The snapshot contains the complete balanced set: all 10,112 questions in
`cladder-v1-q-balanced.json`, read from the archive `data/cladder-v1.zip` at
commit `3d2d1169b4b939a09048a6a75956c8972a93cc38` of causalNLP/cladder. For
each question it includes the given information, the question, the answer,
and the published derivation where there is one, together with the background of the causal
model the question was generated from, taken from
`cladder-v1-meta-models.json` in the same archive. The archive's other
question files, the models' parameters, and the questions' other metadata
are not copied. Both the public repository and the website publish this
content. It is text only, with no code or images.
[Archive at the pinned commit](https://github.com/causalNLP/cladder/blob/3d2d1169b4b939a09048a6a75956c8972a93cc38/data/cladder-v1.zip)

## Changes

Benchopedia builds each task prompt the way the README recommends and the
authors' evaluation script assembles it: the causal model's background, the
question's given information, and the question, each with surrounding
whitespace removed, joined by single spaces. The text is reproduced exactly
as published.

The reference solution is the answer, `yes` or `no`, followed by a blank line
and the published derivation, one step per line, when the question has one.
Keys are the upstream question numbers, and source links point at the archive
at the pinned commit.
