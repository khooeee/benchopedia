# XQuAD redistribution review

## Scope

The snapshot contains all 14,280 question-answer pairs in the twelve XQuAD language files at commit `7d30520c717524000f0d9d2f9c10a069acd9d285` of google-deepmind/xquad: the same 240 paragraphs and 1,190 questions in Arabic, Chinese, English, German, Greek, Hindi, Romanian, Russian, Spanish, Thai, Turkish, and Vietnamese. For each question it includes the question, the title of the Wikipedia article the paragraph comes from, the paragraph, and the single reference answer, in that language. The repository's example image and its baseline result tables are not copied, and neither is the SQuAD v1.1 training data that the README points evaluators to. Both the public repository and the website publish this content. No code or images are copied. [Language files at the pinned commit](https://github.com/google-deepmind/xquad/tree/7d30520c717524000f0d9d2f9c10a069acd9d285)

## Terms

The README at the pinned commit states that the dataset is distributed under the CC BY-SA 4.0 license, and the repository carries the full license text as `CC-BY-SA4.0.txt`, which is kept beside this review as `LICENSE`. That license permits copying, redistribution, public display, and adaptation when the work is credited, a link to the license is given, notices are kept, changes are indicated, and adaptations are shared under the same terms. The repository has no access gate, no separate terms page, and no restriction on publishing the questions and answers. The data files have not changed since Romanian was added in January 2021. [README terms](https://github.com/google-deepmind/xquad/blob/7d30520c717524000f0d9d2f9c10a069acd9d285/README.md#license) and [license text](https://github.com/google-deepmind/xquad/blob/7d30520c717524000f0d9d2f9c10a069acd9d285/CC-BY-SA4.0.txt)

The paragraphs are English Wikipedia text, taken through SQuAD v1.1, and the questions and answers were written by crowdworkers hired by the SQuAD authors; the paper says the paragraphs and questions were then translated by professional translators from Gengo. The English file was checked against `dataset/dev-v1.1.json` in rajpurkar/SQuAD-explorer: all 1,190 questions, their paragraphs, their article titles, and their answer strings appear there unchanged, so the English half of this snapshot is SQuAD v1.1 development content. SQuAD is itself distributed under CC BY-SA 4.0, which permits the translations and permits publishing them under the same license. Wikipedia text is shared under CC BY-SA, and Wikipedia's reuse guidance accepts a link to the article as credit to its contributors; earlier CC BY-SA versions allow adaptations under version 4.0, so publishing the paragraphs and their translations under CC BY-SA 4.0 is consistent with Wikipedia's terms. Every record names its source article, and each task prompt keeps that title. Neither SQuAD nor XQuAD records the article revisions the paragraphs were taken from, so the articles are credited by title and current link; four of the 48 titles, such as Huguenot and Sky (United Kingdom), now redirect to renamed articles. No other third-party content was found. [SQuAD 1.1 paper](https://arxiv.org/abs/1606.05250), [SQuAD terms](https://github.com/rajpurkar/SQuAD-explorer/blob/eee5fdbf62f8613a7812b03419e6b29617b74fd1/views/index.pug), and [Wikipedia's reuse terms](https://en.wikipedia.org/wiki/Wikipedia:Reusing_Wikipedia_content)

A scan of the imported text found no contact details, identifiers, or other personal data beyond what the encyclopedia says about public figures. The only matches for number patterns were historical year ranges such as 973-1050 in the paragraph about the Normans.

## Changes

Benchopedia assembles each task prompt from the question, a line naming the source Wikipedia article, and the paragraph, in the language of that file. The reference solution is the answer string, without its character offset. Keys combine the language code with the upstream SQuAD question ID, which XQuAD repeats across all twelve files, and source links point at the language file at the pinned commit. Question, paragraph, and answer text is unchanged, including the zero-width no-break space that 59 of the translated paragraphs begin with upstream.

## Notices
