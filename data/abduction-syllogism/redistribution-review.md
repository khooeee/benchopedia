# Abductive Reasoning with Syllogistic Forms redistribution review

## Scope

This review covers the complete abduction and deduction TSVs in the authors’
public release at `ed0c05f97727449e01835bc4f1d40064880320c0`. The inputs use the
released rule or premises and choice texts. The reference labels and analysis
categories come from the corresponding source rows. The website and public
repository both display the adapted task and label. [Pinned data directory](https://github.com/kmineshima/abduction-syllogism-llm/tree/ed0c05f97727449e01835bc4f1d40064880320c0/data)

## Terms

The authors explicitly grant Creative Commons Attribution 4.0 International for
this work. The source files are public without a sign-in or agreement. The
paper describes 27 original term triples manually authored for the study and
instantiated using mathematical inference patterns. It names no third-party
text or media in these released rows. The preprint describing the prompt
format also carries CC BY 4.0. [Pinned license declaration](https://github.com/kmineshima/abduction-syllogism-llm/blob/ed0c05f97727449e01835bc4f1d40064880320c0/README.md#license) [Data creation](https://arxiv.org/html/2603.06428v1#S3) [CC BY 4.0 legal code](https://creativecommons.org/licenses/by/4.0/legalcode)

## Changes

Benchopedia converts the TSVs to individual JSONL task records, assigns keys
from the original source index and experimental condition. It places the released
English fields into numbered choices and labeled premise sections. It uses
its own wording for the short task directions and writes the matching
reference number and choice text. The adapted task text remains available
under CC BY 4.0.
