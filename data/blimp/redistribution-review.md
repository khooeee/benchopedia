# BLiMP redistribution review

## Scope

The snapshot contains all of BLiMP: the 67,000 minimal pairs in the 67 files
of `data/` at commit `3e56b06fcabca9b30822fc66435fca6b1aa40bb1` of
alexwarstadt/blimp, 1,000 pairs per file. For each pair it includes the
acceptable and the unacceptable sentence. The paradigm identifier and pair
number appear in each key; the other metadata fields, the repository's model
outputs and human judgments, the paper, and the icon are not copied. Both the
public repository and the website publish this content. It is text only, with
no code or images.
[Data at the pinned commit](https://github.com/alexwarstadt/blimp/tree/3e56b06fcabca9b30822fc66435fca6b1aa40bb1/data)

## Terms

The README at the pinned commit says: "BLiMP is distributed under a CC-BY
license," and links the words to the Creative Commons Attribution 4.0
International license. The authors added that section on 2022-12-13 in the
pinned commit, which changed only the README; the data files are unchanged
since 2019-11-29. The repository has no separate license file. The license
permits copying, redistribution, public display, and adaptation when the work
is credited, a link to the license is given, and changes are indicated. It
adds no non-commercial or share-alike condition. The Hugging Face copy,
`nyu-mll/blimp`, also declares CC BY 4.0, and neither copy is gated or
requires an account or click-through terms. The README asks users to cite the
paper, which is credited below.
[README at the pinned commit](https://github.com/alexwarstadt/blimp/blob/3e56b06fcabca9b30822fc66435fca6b1aa40bb1/README.md),
[the commit that added the license](https://github.com/alexwarstadt/blimp/commit/3e56b06fcabca9b30822fc66435fca6b1aa40bb1),
and [Hugging Face copy](https://huggingface.co/datasets/nyu-mll/blimp)

The sentences are generated by the authors' scripts from templates and a
vocabulary the authors built. The people they mention are first names drawn
from that vocabulary, and a scan of the imported text found no contact
details or web addresses.
[Paper](https://github.com/alexwarstadt/blimp/blob/3e56b06fcabca9b30822fc66435fca6b1aa40bb1/BLiMP.pdf)

## Changes

Benchopedia turns each pair into a two-choice question. The prompt asks which
of the two sentences is grammatically acceptable and lists them numbered 1
and 2, with the acceptable sentence first when the pair number is even and
second when it is odd. The reference solution is the acceptable sentence with
its number. The sentences are reproduced exactly as published. Keys join the
paradigm identifier and pair number, and source links point at the pair's line
in the pinned file.
