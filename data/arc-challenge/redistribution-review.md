# ARC-Challenge redistribution review

## Scope

The snapshot contains all 1,172 questions, choices, and reference answers in the ARC-Challenge test split at revision `210d026faf9955653af8916fad021475a3f00453`. It does not include the Challenge train or validation splits, ARC-Easy, or the science-sentence corpus. Both the public repository and the website publish this test split. [Dataset card](https://huggingface.co/datasets/allenai/ai2_arc/blob/210d026faf9955653af8916fad021475a3f00453/README.md)

## Terms

The pinned dataset card declares CC BY-SA 4.0, and the Allen Institute data page points at the same terms. That grant allows copying and public distribution when attribution is kept, changes are indicated, and the questions remain under the same terms. The card's own licensing section is still marked as needing more information, and the declaration does not clear every underlying exam publisher. No access gate was found. [Dataset card](https://huggingface.co/datasets/allenai/ai2_arc/blob/210d026faf9955653af8916fad021475a3f00453/README.md) and [legal code](https://creativecommons.org/licenses/by-sa/4.0/legalcode)

## Changes

Question and choice text is unchanged. Prompts are assembled with the original labels, and the reference answer is stored as the matching label plus its choice text.
